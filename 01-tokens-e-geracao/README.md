# Kit do aluno: Tokens e geração

Use Python 3.9 ou superior, com a biblioteca padrão. Na pasta deste kit, rode:

```sh
python3 -B simular.py
```

O programa funciona sem instalação adicional, rede, conta de provedor ou credencial. Ele encontra `dados/caso.json` a partir do próprio arquivo, mesmo quando você roda o comando de outra pasta.

Você acompanha a divisão do texto em peças e o sorteio de uma posição de saída. O programa escolhe a maior peça compatível primeiro. Esse algoritmo difere de BPE (codificação por pares de bytes) e dos tokenizadores de produtos. As probabilidades são escolhas para a aula, e os valores de sorteio ficam fixos. O programa calcula os exemplos sem rodar um modelo treinado.

Faça [o exercício de variação](exercicios/variacao.md). Guarde suas contas ou a saída e sua explicação numa pasta sua. Você encontra aqui a demonstração e o enunciado. A solução do exercício autônomo fica com quem conduz o curso.

## Procedência e distribuição

Textos, dados e código são autorais, preparados para a Escola Datarock. O caso é inventado e usa só os valores do arquivo, sem dados de clientes ou fontes externas. Consulte as condições de uso no README principal.
