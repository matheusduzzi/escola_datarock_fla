# Procedência dos dados

O arquivo `caso.json` guarda o vocabulário pequeno, as probabilidades e os valores de sorteio usados na aula. Você pode repetir cada escolha porque os valores ficam fixos, sem gerador aleatório. A divisão em peças ilustra o mecanismo; para medir tokens de um produto, use o tokenizador dele.

A procedência do caso está no README do kit.
