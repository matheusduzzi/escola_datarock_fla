# Fundamentos de LLM e agentes

Kit do aluno do curso **Fundamentos de LLM e agentes**, da Escola Datarock.
Aqui você encontra dados, programas de demonstração, exercícios e testes públicos.
As aulas e as soluções dos exercícios ficam na plataforma do curso.

## Começar

Baixe o ZIP pelo botão **Code → Download ZIP** e extraia os arquivos, ou use Git:

```sh
git clone https://github.com/matheusduzzi/escola_datarock_fla.git
cd escola_datarock_fla
python3 --version
```

Os exemplos usam Python 3.9 ou superior. A aula **JSON Schema e validação** também usa
`jsonschema==4.25.1`; instale pelo `requirements.txt` dela, seguindo seu README.
As demais aulas usam a biblioteca padrão.
Leia o README de cada aula para conferir os comandos e as dependências dela.
Os programas deste kit executam exemplos locais, sem chamar uma API de modelo.
Os dados foram preparados para o curso e não são registros de clientes.
