# Kit da apresentação de Fundamentos de LLM e agentes

Eu uso este kit para ver como está minha preparação e escolher a ordem das aulas do curso.

Na pasta dessa aula no kit, rode `python3 checar_preparo.py`. Você precisa de Python 3.9 ou superior e da biblioteca padrão. O comando olha o arquivo e os tipos dos campos. Você resolve as tarefas para mostrar o que sabe fazer.

Leia `exercicios/diagnostico.md`, resolva as tarefas numa pasta de trabalho sua e preencha `percurso.md`. Depois faça `exercicios/percurso.md`. Guarde comando, saída e explicação de cada tentativa. Se algo falhar, anote o que aconteceu e escolha a preparação para tentar de novo.

O kit contém este README, `checar_preparo.py`, `dados/registros.json`, `dados/LEIA-ME.md`, `exercicios/diagnostico.md`, `exercicios/percurso.md` e `percurso.md`. Os comandos usam só arquivos locais, sem rede, credenciais ou modelo.
