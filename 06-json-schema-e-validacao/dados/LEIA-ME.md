# Procedência

Eu criei os pedidos, prazos, categorias e respostas para testar os limites das regras. Com o ambiente ativado, rode `python -B dados/gerar.py` na pasta dessa aula no kit. O comando recria os dois arquivos JSON byte a byte. O gerador repete os mesmos textos, sem chamar um modelo. O campo `email` tem um texto de exemplo para testar campos extras; ele não serve para contato.
