# Mensagens do exercício

Use `mensagens.json` como entrada para o seu contrato. O arquivo repete as cinco mensagens da tabela do enunciado. Você escreve as saídas esperadas em `conferencia.md`.

## Procedência

As mensagens são autorais e não contêm dados de clientes. A lista é fixa, sem sorteio. O arquivo de dados contém só as entradas do exercício.
