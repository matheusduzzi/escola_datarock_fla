# Kit do curso: Prompt como contrato

Leia a aula e faça o exercício em `exercicios/contrato.md`. Use `dados/mensagens.json` como entrada. Entregue seus próprios `contrato.md` e `conferencia.md`. Você faz a atividade com um editor de texto e a leitura das mensagens.

Para reproduzir a demonstração, rode nessa pasta:

```sh
python3 -B conferir_demo.py
```

O programa requer Python 3.9 ou superior e usa só a biblioteca padrão. Você pode rodá-lo sem instalar pacotes, usar rede ou criar conta. Ele compara estrutura e citação de candidatos escritos à mão, sem chamar modelo ou ler credenciais. A decisão sobre o sentido da mensagem continua com você. O exercício autônomo fica para sua própria checagem.
