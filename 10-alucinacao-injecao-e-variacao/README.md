# Kit: Alucinação, injeção e variação

Abra a pasta dessa aula no kit do curso. Leia `exercicios/parecer.md` e `dados/casos.json`, depois escreva seu parecer em um arquivo seu. A atividade é de leitura; você pode fazê-la sem usar um modelo.

Para rodar a demonstração, nessa mesma pasta:

```sh
python3 -B demonstrar.py
```

Use Python 3.9 ou superior. O script usa só a biblioteca padrão, sem instalar pacotes, acessar a rede ou gastar créditos de API.

`dados/demonstracao.json` traz os exemplos A, B e C. O programa checa os tipos e imprime os campos. Você compara os valores com a fonte. `dados/casos.json` traz os seis casos do exercício, com documentos, pedidos e respostas para analisar.

Se precisar de ajuda, deixe um comentário na aula com seu objetivo, o caso ou comando, a saída e o que já tentou, sem dados pessoais.

## Sobre os arquivos

Os exemplos foram escritos para a Escola Datarock, sem coleta de dados de pessoas ou empresas. Os arquivos dessa pasta formam o kit do aluno. As respostas do instrutor ficam separadas.
