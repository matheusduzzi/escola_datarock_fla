# Procedência dos dados

Todos os casos da Loja Farol são fictícios. Gerador: `../gerar_dados.py`, com literais fixos e nenhuma aleatoriedade. Os oito envelopes foram escritos para exercitar sucesso, incompletude, autenticação, ritmo, saldo, serviço, timeout e corpo inválido. Contadores de tokens são construídos; não são tokenização nem uso medido. Fixtures reduzidas, não respostas integrais da API. Nenhum dado pessoal, segredo ou log operacional é necessário.
