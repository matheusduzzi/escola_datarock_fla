# Kit do aluno: ferramenta e laço do agente

Use Python 3.9 ou superior. O exemplo roda sem pacotes adicionais, conta, credencial ou rede.

Abra a pasta dessa aula no kit do curso e rode:

```sh
python3 -B simular.py
```

Leia `dados/casos.json` ao lado do resultado. As respostas estão numa lista programada. O campo `historico` mostra os resultados que uma integração poderia enviar ao modelo na próxima chamada. Aqui, a próxima resposta vem da lista fixa e não depende do histórico.

O exercício está em `exercicios/diagrama.md`. Faça seu diagrama e sua explicação em arquivos novos. Você pode manter o simulador como está. Na próxima aula, “Executar ferramenta fictícia”, você programa seu próprio loop.

Se precisar de ajuda, deixe um comentário na aula com o objetivo, o comando, a saída e o que já tentou. Retire dados pessoais antes de enviar.

Conteúdo e dados preparados para o curso. Consulte `dados/LEIA-ME.md` para saber de onde vêm os casos.
